# Papurr(論文フォルダ管理)

*English version: [README.md](README.md)*

論文を**自分で選んだ1つのフォルダ**にまとめ、**indexを生成して管理**するChrome 拡張機能です。
いつものwebデータベースでPDF のリンクをクリックすると、持っている論文なら手元の PDF が開き、なければフォルダに保存してから開きます。拡張機能自体はオフラインでも動きます。

## コンセプト

論文、同じものを何度もダウンロードしがち。\
分類が面倒で、デスクトップやダウンロードフォルダに放置しがち。\
そのうち掃除して消しがち。\
で、また同じ論文をダウンロードしがち。\
プロジェクトごとにフォルダを分けると、同じ論文をあちこちにコピーしがち。\
あっちのコピーには書き込みがあるのに、こっちには無い、が起きがち。

文献管理ソフトを入れてみても、機能が多すぎて使いこなせなかったりしがち。\
同期のどこかで、なぜか何かが消えがち。\
たまにフリーズしがち。\
結局、論文を探すのはINSPIREやADSのほうが便利で、\
管理ソフトにある論文を、なんとなくまたダウンロードしがち。

Papurrは、この「しがち」を終わらせます。
論文は1つのフォルダに1部だけ。PDFのリンクをクリックすると、持っていれば手元のPDFが開き、なければ保存してから開きます。プロジェクトの分類は、コピーではなくタグで。


## 主な機能

- **arXiv 版とジャーナル版をまとめて管理**(ジャーナル版しかない論文や、NASA ADS の古いスキャン版も扱えます)
- **ライブラリ画面**: 検索・並べ替え・絞り込み・タグ、arXiv / INSPIRE / NASA ADS へのリンク
- **論文ごとのノート**(フォルダ内の Markdown ファイル。数式も表示できます)
- **手持ちの PDF の取り込み**: 中身を読んで判別し、承諾したものだけ名前を変えてライブラリに追加します
- **今日のarXiv**: フォローするカテゴリの最新の論文を、アブストラクト付きで一覧
- **INSPIRE 検索**: INSPIRE のデータベースを API 経由で検索。結果はワンクリックで保存できます
- **AI 機能(任意)**: ご自身の Claude・ChatGPT・Kimi Code のプランで、今日のarXivを研究との関連度順に並べ替え、推薦理由・翻訳・要約
- **クラウド同期のフォルダに対応**、日本語・英語・簡体字中国語の画面、色のテーマ

## インストール

現在は Chrome ウェブストアではなく、「パッケージ化されていない拡張機能」として読み込みます。次の 2 通りの方法があります。

### A. AI に任せる（おすすめ）

Claude Code(`claude`)、Codex CLI(`codex`)、Kimi Code CLI(`kimi`)などの AI の CLI を利用している場合：

1. Papurr を置くディレクトリでリポジトリを取得します: `git clone https://github.com/atsuhisa-ota/papurr.git`
2. ご利用中のAI の CLI でPapurr を開き、「**docs/INSTALL-AGENT.mdにしたがってPapurrをインストールしてください**」と依頼するだけ。
3. ただし、次の操作はユーザーが実行してください：
   - `chrome://extensions` で、案内されたフォルダを拡張機能として読み込む。
   - 補助プログラムを登録した場合は、Chrome を再起動する
   - Papurr の設定で論文フォルダを選ぶ
   - AI 機能を使う場合は、AI のプランへのサインインと、設定画面での同意
4. ツールバーの Papurr のアイコンを押すとライブラリが開きます。

AI は、確認なしに何かをインストールしたり、サインインやパスワードを扱ったり、リポジトリのファイルを書き換えたりはしません。
更新するときも、同じフォルダで開いたチャットで「Papurrを更新してください」と頼めます。

### B. 手作業でインストールする

1. リポジトリを取得します(上の A の 1 と同じです)。
2. `chrome://extensions` を開き、**デベロッパー モード**をオンにします。
3. **パッケージ化されていない拡張機能を読み込む**を押し、このリポジトリの `extension` フォルダを選びます。
4. ツールバーの Papurr のアイコンを押すとライブラリが開きます。右上の**設定**を開き、**論文フォルダを選びます**。
5. 外部の PDF アプリ、「フォルダに表示」、AI 機能を使う場合は、補助プログラムをパソコンごとに 1 回登録し(Python 3 が必要です)、
   Chrome を再起動します。
   - Mac: `native/Install helper (Mac).command` をダブルクリック
   - Windows: `native\Install helper (Windows).bat` をダブルクリック
   - Linux: このフォルダで `python3 native/install.py` を実行(Chrome は Google 配布の .deb / .rpm 版。snap 版・Flatpak 版では動きません)
6. 更新するときは、`git pull` のあと `chrome://extensions` で Papurr の更新ボタンを押し、開いているタブを再読み込みしてください。新しい版の知らせは、GitHub のページの **Watch → Custom → Releases** で受け取れます。インストール済みの版は、設定と使い方のページに表示されます。

## 補足
- **クラウドと同期しているフォルダを使う場合、同期が済んでいるかはご自身で確認してください。** Papurr は同期の状態を確認しません。
  同期の途中で「インデックスを更新」を押すと、未同期のファイルの項目が外れることがあります。
- Chrome の再起動後にフォルダへのアクセス許可を求められたときは、**「毎回許可する」**を選ぶと、次回から確認されなくなります。
- ジャーナルの PDF は、お使いのブラウザのログイン状態のまま取得します。PDF を閲覧できる環境(大学のネットワークなど)が必要です。
  取得できない場合は、通常の方法で開いて論文フォルダに保存し、設定の「判別して名前を変更…」を使ってください。

## 使い方

画面の右上にもある**使い方**から読めます。
設定画面の各セクションの **?** からも、その部分の説明に移動できます。

## データの扱い

Papurr が問い合わせるのは、論文の情報を調べるための arXiv・INSPIRE・OpenAlex・Crossref・NASA ADS と、クリックした PDF の出版社のサイトだけです。
PDF ファイルをアップロードすることはなく、作者に何かが送信されることもありません。AI 機能を使う場合だけ、ご自身の AI のコマンドを通して、
その提供元に論文の情報などが送信されます(詳しくは「使い方」と設定画面の同意文)。

## リポジトリの構成

| フォルダ | 内容 |
| --- | --- |
| `extension/` | 拡張機能の本体(Chrome に読み込むもの)。 |
| `native/` | 外部の PDF アプリや AI のコマンドを使うための補助プログラム(任意)。 |
| `dev-tests/` | 自動テスト。`dev-tests/run-all.sh` で実行します(`node`、`python3`、Google Chrome が必要です)。 |
| `docs/`、`CLAUDE.md`、`AGENTS.md` | 開発者と AI アシスタント向けの開発ガイド(英語): コンセプト、構成、データ形式、守るべきルール。`docs/DATA-SOURCES.md` は、Papurr が何に問い合わせるか、その理由を一覧にしたものです(英語)。 |

## 現状と制限

- Google Chrome(Mac と Linux)で開発・確認しています。Windows 用の補助プログラムは、まだ実機で確認していません。Chrome ウェブストアでは、まだ公開していません。
- 公式のソースは <https://github.com/atsuhisa-ota/papurr> です。作者が Chrome ウェブストアで公開した場合は、ここにリンクを載せます。「Papurr」という名前の拡張機能がほかにあっても、作者のものではありません。
